# Grammatikbegriffe

## Word types

| German | English | Example |
|---|---|---|
| das Nomen / das Substantiv / das Hauptwort | noun | der Stift, die Wohnung |
| das Verb | verb | kommen, haben |
| der Artikel | article | der, ein, kein |
| der bestimmte Artikel | definite article | der, die, das |
| der unbestimmte Artikel | indefinite article | ein, eine |
| das Pronomen | pronoun | das Buch → es |
| das Personalpronomen | personal pronoun | ich, du, er, sie, es |
| das Indefinitpronomen | indefinite pronoun | Man isst in Italien Pizza. |
| der Possessivartikel | possessive article | mein, dein, Ihr |
| das Fragewort | question word | wer, wen, was, wo |
| die Präposition | preposition | in, aus, nach |

## Nouns

| German | English | Example |
|---|---|---|
| das Genus | gender | der · die · das |
| maskulin / feminin / neutral | masculine / feminine / neuter | der Stift · die Wohnung · das Auto |
| der Singular | singular (one) | der Stift |
| der Plural | plural (more) | die Stifte |
| der Umlaut | umlaut | das Haus → die Häuser |

## Verbs

| German | English | Example |
|---|---|---|
| der Infinitiv | infinitive (basic form) | kommen |
| der Verbstamm | stem | komm- |
| die Endung | ending | ich komm-e, du komm-st |
| die Konjugation | conjugation | ich komme, du kommst, er kommt |
| der Vokalwechsel | vowel change | ich nehme → du nimmst |
| das Präsens | present tense | ich bin |
| das Präteritum | simple past | ich war |

## Sentences and questions

| German | English | Example |
|---|---|---|
| der Aussagesatz | statement | Ich habe einen Stift. |
| die W-Frage / die Ergänzungsfrage | W-question | Was hast du? |
| die Ja-/Nein-Frage / die Satzfrage | yes/no question | Hast du einen Stift? |
| das Subjekt | subject (Wer? Was?) | Nico besucht Lisa. → Nico |
| das Objekt | object (Wen? Was?) | Nico besucht Lisa. → Lisa |

## Cases

| German | English | Example |
|---|---|---|
| der Kasus / der Fall | case | Nominativ, Akkusativ, … |
| der Nominativ | subject case | Der Stift ist hier. |
| der Akkusativ | object case | Ich habe den Stift. |

## du and Sie

| German | English | Example |
|---|---|---|
| informell / formell | informal / formal | du · Sie |
| die Höflichkeitsform | polite form | Sie |
| duzen | to use du with someone | Wie heißt du? |
