- sein is Nominative form, it takes:
    - m: der/ein/kein
    - f: die/eine/keine
    - n: das/ein/kein
    - p: die/-/keine
- haben is Akkusativ form, it takes:
    - m: den/einen/keinen
    - f: die/eine/keine
    - n: das/ein/kein
    - p: die/-/keine

```text
NOMINATIV  (sein: Das ist … / Das sind …)
    der/die/das            ein/eine               kein/keine
m   Das ist der Stift.     Das ist ein Stift.     Das ist kein Stift.
f   Das ist die Wohnung.   Das ist eine Wohnung.  Das ist keine Wohnung.
n   Das ist das Auto.      Das ist ein Auto.      Das ist kein Auto.
pl  Das sind die Autos.    Das sind Autos.        Das sind keine Autos.

AKKUSATIV  (haben: Ich habe …)
    den/die/das            einen/eine             keinen/keine
m   Ich habe den Stift.    Ich habe einen Stift.  Ich habe keinen Stift.
f   Ich habe die Wohnung.  Ich habe eine Wohnung. Ich habe keine Wohnung.
n   Ich habe das Auto.     Ich habe ein Auto.     Ich habe kein Auto.
pl  Ich habe die Autos.    Ich habe Autos.        Ich habe keine Autos.

Only the masculine changes:  der → den,  ein → einen,  kein → keinen.

From the lesson script:
  Nein, im Haus ist kein Aufzug.        sein  → Nominativ (m)
  Hast du einen Stift?                  haben → Akkusativ (m)
  Nein, ich hab keinen Stift.           haben → Akkusativ (m)   hab = spoken habe
  Ja, die Wohnung hat eine Terrasse.    haben → Akkusativ (f)
```

```text
Wer? = who (subject)   ·   Wen? = whom (accusative object)   ·   Was? = what (thing, both)

Nico besucht Lisa.
  Wer besucht Lisa?    → Nico    (Nico does the action: subject)
  Wen besucht Nico?    → Lisa    (Lisa gets the action: accusative object)
```

Extra grammar

```text
Einen Moment bitte.  =  (Warten Sie) einen Moment, bitte.

der Moment (m): a length of time is in the accusative → ein → einen
  Ich bleibe einen Tag.     der Tag (m)   → einen
  Ich bleibe ein Jahr.      das Jahr (n)  → ein (no change)
```
