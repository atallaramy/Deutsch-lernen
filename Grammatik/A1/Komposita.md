# Komposita: compound nouns

*das Kompositum* · A1 · from DW A1 E6 L3 *Sofa, Sessel und Tisch* · checked 2026-10-18

## The rule

German terms:
- *das Kompositum* (compound: A composite is a compound word. This word is often a noun but it can be, for example, a verb or adjective. The different components of a compound can also be different types of words. The base word determines which type of word this compound is.)

1. German joins two or more words into one new noun, written as **one word**:
   *der Spiegel + der Schrank → der Spiegelschrank*.
2. The **last noun** is the base noun: it says what the thing is. The words before it
   say more about it: a *Spiegelschrank* is a *Schrank* with mirrors.
3. The base noun gives the compound its **article** and its **plural**:
   *der Schrank → der Kleiderschrank*, *die Schränke → die Kleiderschränke*.
4. The first part can be a noun, a verb or an adjective: *schlafen + das Zimmer →
   das Schlafzimmer*, *hoch + das Haus → das Hochhaus*.
5. Sometimes a sound joins the parts: *Küche**n**schrank*, *Arbeit**s**zimmer*,
   *Kind**er**zimmer*. Learn these with the word; there is no need to learn rules for it.

Source: DW grammar page [Word formation: compounds](https://learngerman.dw.com/en/word-formation-compounds/l-37438475/gr-38304035) (E6 L3)
and the exercises [Compounds](https://learngerman.dw.com/en/compounds/l-37438475/e-37442044) and
[Compounds and articles](https://learngerman.dw.com/en/compounds-and-articles/l-37438475/e-37442131).

## Table

| first part | base noun | compound |
|---|---|---|
| der Spiegel | **der** Schrank | **der** Spiegel**schrank** |
| die Küche | **der** Schrank | **der** Küchen**schrank** |
| das Büro | **der** Stuhl | **der** Büro**stuhl** |
| die Bücher | **das** Regal | **das** Bücher**regal** |
| stehen (verb) | **die** Lampe | **die** Steh**lampe** |
| schlafen (verb) | **das** Zimmer | **das** Schlaf**zimmer** |
| tanken (verb) | **die** Stelle | **die** Tank**stelle** |
| hoch (adjective) | **das** Haus | **das** Hoch**haus** |

Plural like the base noun: *der Stuhl → die Stühle*, so *der Bürostuhl → die Bürostühle*.
